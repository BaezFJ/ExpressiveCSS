## Focused check findings

The new static regression failed before rules existed. After adding the rules, it exposed that the shared name heuristic accepted a nav landmark solely from its child button text. The source helper now requires an authored name for native nav elements; blank names fail and valid aria-labelledby passes. The generator copied that shared helper into MCP.

The first documentation check rejected five new checkboxes without the framework-required label wrappers. Documentation and paging fixtures now use those wrappers. A localized-number regression initially assumed generic Arabic used Arabic-Indic digits; this runtime uses Latin digits for that locale. The test now requests Egyptian Arabic explicitly and verifies the literal localized page numbers. These failures were corrected without changing runtime locale behavior or weakening the checks.
