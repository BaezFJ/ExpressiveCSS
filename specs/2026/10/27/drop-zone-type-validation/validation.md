## Disabled-state boundary

Disabled controls expose an empty validationMessage even while a custom error remains, as the [HTML validation API contract](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#dom-cva-validationmessage) specifies. Clearing such an unreadable value could erase an application error. Inactive controls therefore keep native validity untouched, including during reset. R1 explicitly requires silent Forms.validateField after scripted enabling/constraint changes. A regression preserves an application message changed while disabled across reset and validation after enabling. Browser checks will also verify refresh after a disabled owned-error reset.
