## Accepted extensions and limits

Phase 71 deliberately extends the earlier local page-size no-event contract by adding one cancelable `expressive:page` request before defaults. It does not add selection/filter/sort events during page navigation. Current assertions cover that accepted extension. Phase 76 deliberately extends Phase 75 single-tree search to native multiple trees while retaining single behavior.

Phases 73/74 generalize Phase 72 private type helpers into shared failure, constraint, precedence and validity-ownership paths. Type matching remains explicitly opt-in. Changed effective size/count constraints can report an unchanged file selection again; equivalent decimal limits remain deduplicated. The corrected zero-delay reset timer supersedes the earlier Phase 72 microtask increment, checking cancellation after dispatch.

Phase 68 visual comparison was explicitly skipped because it changed no layout; no visual pass is invented. Later intended documentation differences were inspected as differences. Phase 76 final comparisons retain all eight Phase 75 baseline hashes. Final TreeSelect header/content and eight fresh light/dark states were inspected; four final Select images match earlier inspected images pixel for pixel. Distinct selection/focus fills and contained feedback have actual browser evidence.

Physical devices, native browser zoom, OS IME and spoken screen-reader output remain unavailable. Synthetic composition events establish guards only; forced colors and reduced motion are browser emulation. Phase 70 Firefox pointer evidence uses an inline native select, followed by restored closed-select keyboard checks; it does not establish pointer use in the OS popup. Trusted native protocol file-drop evidence is Chromium-only; Firefox/WebKit cover the file-change boundary. Application network response ordering and server-side validation remain application responsibilities. Historical failed runs and source pins retain their original scope; current evidence does not invent coverage for them.
