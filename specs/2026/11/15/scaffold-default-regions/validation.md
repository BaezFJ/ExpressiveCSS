## Decisions made while building

- The landmark rule lists landmark, `region`, `document` and `application` roles instead of `[role]`. A bare `[role]` blocks every composite role, and the semantics test then requires the row to account for each one.
- A trailing `:is(.toolbar.vertical, …, .scaffold-trailing)` rule gives `.scaffold-trailing` the toolbar's (0,3,0) specificity, so only the toolbars get the centering and margin rule.
- The docs example keeps the skip link inside the `<header>`: a focused skip link that is a direct child of the scaffold would land in a free grid cell below the window.
- `mcp/expressivecss/smoke.mjs`: the "app bar" catalogue search now finds 5 entries, and the resource completion helper models the SDK's 100-value cap. The 101st guide made the empty-prefix completion report `hasMore: true` with `total: 101`, which is what the server should send.
