Collections

A list. The HTML is the component.

A .collection is a list of rows. There is no JavaScript. .collection-item is optional — a direct <li> is enough.

  • Alvin
  • Alvin
  • Alvin

<ul class="collection">
  <li>Alvin</li>
  <li>Alvin</li>
  <li>Alvin</li>
</ul>

The box is 12px and uses --md-comp-collection-shape. Add flush for a borderless list.

  • Alvin
  • Alvin
  • Alvin
<ul class="collection flush">…</ul>

Links

Put the link in the item. Mark the current row with aria-current="page" (or the older active class).

  • Alvin
  • Alvin
  • Alvin
  • Alvin
<ul class="collection">
  <li><a href="/inbox">Inbox</a></li>
  <li><a href="/sent" aria-current="page">Sent</a></li>
</ul>

Headers

A heading as the first child of an item is the section header. with-header and collection-header still work.

  • First names

  • Alvin
  • Alvin
  • Alvin
<ul class="collection">
  <li><h3>First names</h3></li>
  <li>Alvin</li>
</ul>

Secondary content

A trailing action uses secondary-content. It sits at the end of the row — no float.

  • Alvin send
  • Alvin send
  • Alvin send 
<li>
  Alvin
  <a href="#!" class="secondary-content">
    <i class="material-symbols">send</i>
  </a>
</li>

Avatars

A leading .circle (image or icon) is the avatar. .avatar is optional. .title is the headline; a following <p> is supporting text.

Class aliases

The older class names still work: collection-item, collection-header, with-header, avatar, and a <div class="collection"> of bare <a class="collection-item"> links.

Alvin Alvin Alvin 
<div class="collection">
  <a href="#!" class="collection-item">Alvin</a>
  <a href="#!" class="collection-item active">Alvin</a>
</div>
