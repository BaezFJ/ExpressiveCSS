Parallax

A cropped image that shifts as it crosses the viewport.

A .parallax (or <figure class="parallax">) clips an <img>, <picture>, or <video>. As the clip crosses the viewport the media shifts, slower than the page. There is no inner wrapper and no scroll listener — the motion is CSS (animation-timeline: view()). Without that API the image is just object-fit: cover.

AutoInit() still matches .parallax, but you do not need it for the effect. A missing image logs an error and returns. Prefer an image taller than the clip, or a srcset that is; a short image has less to move. 

<figure class="parallax">
  <img src="images/lake.jpg" alt="A mountain lake">
</figure>

Overlay

A heading or <p> is centered on the image. A <figcaption> docks to the bottom on a translucent surface, the same idea as a card figure. 

<figure class="parallax">
  <img src="images/coast.jpg" alt="">
  <figcaption>A rocky coastline.</figcaption>
</figure>

<div class="parallax">
  <img src="images/lake.jpg" alt="">
  <h2 class="on-primary-text">Visit the lake</h2>
</div>

Tokens

Override these on the clip. Height is how much of the image you see; travel is how far it moves. Shape matches media, lightbox, and slider. Add max for a full-viewport hero with no corners.

Token Default
--md-comp-parallax-height 500px
--md-comp-parallax-travel 120px
--md-comp-parallax-shape 12px 
<figure class="parallax" style="--md-comp-parallax-height: 300px">
  <img src="images/hills.jpg" alt="Clouds over hills">
</figure>

<figure class="parallax max">…</figure>

Motion follows prefers-reduced-motion. When the user asks for less, the image stays a static cover.

Initialization

Optional. The IIFE still exposes Expressive.Parallax so existing init / AutoInit calls keep working. They do not attach scroll or resize listeners. 

document.addEventListener('DOMContentLoaded', function() {
  const elems = document.querySelectorAll('.parallax');
  const instances = Expressive.Parallax.init(elems);
});

Methods

const instance = Expressive.Parallax.getInstance(elem);
.destroy();

Drop the instance stash. There are no listeners to tear down.

instance.destroy();
