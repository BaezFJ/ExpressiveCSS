Modals

Material Design 3 dialogs, from the HTML.

A <dialog> is a basic dialog. A heading is the headline, a <p> (or a wrapping <div>) is supporting text, and the last child <form method="dialog"> or <nav> is the action row. There is no modal-header, modal-content, or modal-footer class.

Tokens follow the M3 dialog spec. The container is surface, 28dp corners, 280–560dp wide, elevation 3. The headline is headline-small / on-surface; supporting text is body-medium. The scrim is 32% scrim with a 12px blur. Opening with showModal() also stops the page behind it from scrolling. Actions sit at the end with an 8dp gap.

Open it with showModal() and close it with close() — the Dialog API, not a plugin.

A <form method="dialog"> closes the dialog when a submit button is pressed and sets dialog.returnValue from the button’s value. An optional leading <i> is the M3 dialog icon. Tapping the scrim closes it too, but only if the press and the release both miss the dialog.

Methods

Call these on the <dialog> element. See HTMLDialogElement for the full API.

.showModal()

Open as a modal, with the scrim.

dialog.showModal();
.close()

Close the dialog.

dialog.close();

A tap or click on the scrim also closes it. Both ends of the gesture have to land outside the dialog’s box, so a drag that starts on the dialog — selecting text, missing a button — cannot dismiss it. Set closedby="none" or closedby="closerequest" to opt out.

Tokens

Override these on the <dialog> if you need a different surface or width.

Token Default
--md-comp-basic-dialog-container-color --md-sys-color-surface
--md-comp-basic-dialog-container-shape 28px
--md-comp-basic-dialog-container-min-width 280px
--md-comp-basic-dialog-container-max-width 560px
--md-comp-basic-dialog-sheet-width 400px
--md-comp-basic-dialog-scrim-blur 12px

Sheets

Add top, right, bottom, or left to dock the dialog to that edge. The inner corners keep the 28dp shape; the edge against the viewport is square. top-sheet, right-sheet, bottom-sheet, and left-sheet are aliases. Side sheets are 400px wide (--md-comp-basic-dialog-sheet-width); top and bottom take the full width and half the viewport height.

Top sheet

Docked to the top. Useful for a compact status or filter bar.

Right sheet

A side sheet for details, filters, or a short form that should stay next to the page.

Bottom sheet

Bottom sheets are useful for a short list of actions.

Left sheet

A side sheet docked to the start edge. Same width token as the right sheet.

 
<dialog class="top">…</dialog>
<dialog class="right">…</dialog>
<dialog class="bottom">…</dialog>
<dialog class="left">…</dialog>

Full-screen

Add max for a full-viewport dialog with no corners. That is the M3 full-screen dialog, typically used on small screens.

New message

A full-screen dialog fills the viewport. Put the primary action in the form at the end.

 
<dialog class="max">
  <h2>New message</h2>
  <p>A full-screen dialog fills the viewport.</p>
  <form method="dialog">
    <button type="submit" class="text">Close</button>
    <button type="submit">Save</button>
  </form>
</dialog>
