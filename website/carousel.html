Carousel

A 3D coverflow, or a linear snap track.

A .carousel is a row of items. The default is a perspective stack: the center item is large, the others recede. Add flat for a full-width snap track — that motion is CSS. This is not the Slider on the Media page; that component crossfades captions.

Direct children move. .carousel-item is optional. AutoInit() starts every .carousel except those marked no-autoinit. 

<div class="carousel">
  <img src="images/sample-1.jpg" alt="Mountain lake">
  <img src="images/sample-2.jpg" alt="Forest path">
  <img src="images/sample-3.jpg" alt="Rocky coastline">
</div>

With no items, init logs an error and returns. The track is 400px tall; set --md-comp-carousel-height (or the older --carousel-height) to change it. Coverflow items are half that size. Arrow keys move the focused carousel.

Flat (snap)

Add flat for a linear track. Slides snap. Swipe is native scrolling — no drag physics. carousel-slider and fullWidth: true still enable this mode. 

<div class="carousel flat">
  <img src="images/sample-1.jpg" alt="Mountain lake">
  <img src="images/sample-2.jpg" alt="Forest path">
</div>

Swipeable tabs wrap their panels in a flat carousel. That is the Tabs plugin.

Tokens

Token Default
--md-comp-carousel-height 400px
--md-comp-carousel-shape 12px
--md-comp-carousel-gap 0

--carousel-height is still read if you set it. prefers-reduced-motion turns off snap smoothing and the coverflow tween.

Initialization

document.addEventListener('DOMContentLoaded', function() {
  const elems = document.querySelectorAll('.carousel');
  const instances = Expressive.Carousel.init(elems, {
    // specify options here
  });
});
Expressive.AutoInit(document.body, {
  Carousel: { indicators: true }
});

Options

Name Type Default Description
duration Number 200 Coverflow tween, in milliseconds. Snap mode uses CSS.
dist Number -100 Coverflow zoom. 0 keeps every item the same size. Flat mode forces this to 0.
shift Number 0 Extra spacing on the center coverflow item.
padding Number 0 Padding between non-center coverflow items.
numVisible Number 5 How many coverflow items stay visible.
fullWidth Boolean false Same as adding flat. Kept so existing calls compile.
indicators Boolean false Show paging dots. Only drawn when there is more than one item.
noWrap Boolean false Stop at the ends instead of wrapping. Flat tracks never wrap. A single-item carousel always behaves as if this were true.
onCycleTo Function null Called when a new item becomes the center. Receives the current item and whether the move was a drag.

Methods

const instance = Expressive.Carousel.getInstance(elem);
.next(); / .prev();

Move one item, or pass how many.

instance.next();
instance.prev(3);
.set();

Move to a 0-based index. Optional one-shot onCycleTo.

instance.set(3);
.destroy();

Tear down listeners, generated dots, and inline transforms.

instance.destroy();
