Toolbars

Frequently used actions for the current page.

Toolbars display frequently used actions relevant to the current page. Two variants: a floating toolbar and a docked toolbar. Use the vibrant color style for greater emphasis. They can hold buttons, icon buttons, and text fields, and a floating bar can sit next to a FAB. Do not show a toolbar at the same time as a navigation bar.

A <nav class="toolbar"> is the bar. Direct <button> or <a> children are the actions. An <i> is the icon; wrap a label in <span>. .active marks the selected action. .filled on an action is the emphasized control. They are CSS only — nothing to AutoInit.

Tokens follow the M3 toolbar spec. The default is floating: it hugs its actions, 64dp tall, 32dp stadium corners, surface-container, elevation 2. Docked is full width, the same 64dp (shorter than the old bottom app bar), square, no elevation. Actions are 48dp targets with a 24dp icon, transparent at rest. Selected is secondary-container.

This is not the FAB-to-toolbar transition (div.fixed-action-btn.toolbar). That stays on Floating Action Button.

Floating

The default. Horizontal or vertical. Standard or vibrant. It can hold many controls, and it can sit next to a FAB. 

<nav class="toolbar" aria-label="Call controls">
  <button type="button" aria-label="Stop camera">
    <i class="material-symbols">videocam_off</i>
  </button>
  <button type="button" class="active" aria-label="Hand">
    <i class="material-symbols">back_hand</i>
  </button>
  <button type="button" aria-label="More">
    <i class="material-symbols">more_vert</i>
  </button>
</nav>

A label next to the icon needs a <span> — :only-child ignores text nodes, so <i>edit</i>Edit would look icon-only. .filled on an action is the emphasized control (16dp corners, primary). 

<nav class="toolbar" aria-label="Editor">
  <button type="button" aria-label="Undo">
    <i class="material-symbols">undo</i>
  </button>
  <button type="button" class="filled" aria-label="Add">
    <i class="material-symbols">add</i>
  </button>
  <button type="button" aria-label="More">
    <i class="material-symbols">more_vert</i>
  </button>
</nav>

Color

Standard is surface-container. vibrant (or filled on the nav) is primary-container / on-primary-container — use it when the bar needs more emphasis. Selected then uses surface so it still contrasts. 

<nav class="toolbar vibrant" aria-label="Text format">…</nav>

Vertical

vertical stacks the actions. Only floating bars go vertical — a docked bar stays a horizontal strip. 

<nav class="toolbar vertical" aria-label="History">…</nav>

Docked

docked (the M3 name; max is the BeerCSS alias) stretches the bar to the full width, drops the stadium and the elevation, and spaces the actions. It replaces the bottom app bar: same job, shorter (64dp, not 80). Use it for page actions; destinations belong on a navigation bar, and the two should not appear together. A child .max is a spacer, not the bar.

Text actions and a spacer: 

<nav class="toolbar docked" aria-label="Page actions">
  <button type="button" aria-label="Download">
    <i class="material-symbols">download</i>
  </button>
  …
</nav>

<nav class="toolbar docked" aria-label="Wizard">
  <button type="button"><span>Back</span></button>
  <span class="max"></span>
  <button type="button" class="filled"><span>Next</span></button>
</nav>

Pairing with a FAB

Wrap the toolbar and a sibling .extra.circle FAB in .toolbar-group. The FAB stays a FAB — 56dp, 16dp corners, its own color — and sits 8dp from the bar. That is the companion FAB, not the in-bar .filled action. 

<div class="toolbar-group">
  <nav class="toolbar vibrant" aria-label="Message actions">…</nav>
  <button type="button" class="extra circle tertiary-container on-tertiary-container-text" aria-label="Reply">
    <i class="material-symbols">reply</i>
  </button>
</div>

Fixed

fixed pins the bar to the viewport. A floating bar sits 16dp from the bottom-center; add top to move it to the top. A vertical bar sits on the start edge; right flips it. A docked bar sticks to the bottom edge; top sticks it to the top. 

<nav class="toolbar fixed" aria-label="Format">…</nav>
<nav class="toolbar vertical fixed" aria-label="Tools">…</nav>
<nav class="toolbar docked fixed" aria-label="Editor">…</nav>
