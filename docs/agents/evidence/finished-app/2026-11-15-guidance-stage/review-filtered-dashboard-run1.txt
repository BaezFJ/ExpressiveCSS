No manual `.init()`, no repeated AutoInit, no retired global `M`, and nothing is removed, so no `destroy()` is needed. `DataTables.sync`/`showPage` are documented public calls, and `showPage` fires no events (dist/types/behaviors/dataTables.d.ts:62).
- Assets and fonts: one compiled stylesheet, no Google Fonts or Material Icons links, `.material-symbols` only (no `.material-icons`), and `dist/fonts/` sits next to `dist/css/`. The JS bundle is justified because the page uses Tabs and DataTables paging and sorting. No render-blocking script in `<head>`.
- States: no custom CSS removes focus rings. Every filter result has an empty state (index.html:97–104, toggled at :249–252), and Clear filter puts focus back on the input (:275). Data is synchronous sample data, so no loading or error state applies. Page buttons are native `button type="button"` controls and their disabled state belongs to the framework. Paging hides rows with `data-table-page-hidden`, not `hidden`, so the result count at :231 counts all matches, not just the current page.

No sticky header or sheet can hide focus (2.4.11). The Tabs indicator stops under reduced motion (tabs.md options) and the page adds no motion of its own.
